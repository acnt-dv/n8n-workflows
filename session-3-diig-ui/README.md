# Dotin Session 3 — Diig UI Assistant

دستیار n8n برای ساخت رابط کاربری فارسی و RTL با استفاده از دو MCP رسمی:

- **دیگ** برای جست‌وجو و دریافت کامپوننت و نمونهٔ استفاده: https://docs.digdesign.ir/api/mcp
- **دیگچه** برای جست‌وجو و دریافت SVG آیکون: https://icons.digdesign.ir/api/mcp

Agent ابتدا کامپوننت را از دیگ بررسی می‌کند. فقط اگر درخواست به آیکون نیاز داشته باشد، دیگچه را هم فراخوانی می‌کند. پاسخ شامل کد یکپارچه، دلیل انتخاب کامپوننت/آیکون و متن کوتاه README برای محصول تولیدشده است. اگر MCP گزینهٔ مناسبی پیدا نکند، Agent باید این موضوع را اعلام کند و کد خیالی نسازد.

## وارد کردن workflow

در n8n از **Import from File**، فایل `Diig_UI_Agent.json` را وارد کنید. workflow از credential مدل OpenAI موجود در پروژه استفاده می‌کند. سپس آن را بازبینی و منتشر کنید تا در Chat Hub قابل استفاده شود.
